# Travel Mind 前端设计标准

## 方向

Claude Code 式简洁纸张风：暖白纸面、深色文字、细分隔线、单一暖橙动作色。用户端与管理端共享同一套视觉语言，差异只来自信息密度，不再各自定义主题。

## 设计令牌

| 角色 | 值 | 用法 |
| --- | --- | --- |
| 页面 | `#F7F5F0` | 全局背景 |
| 纸面 | `#FFFFFF` | 卡片、表单、顶栏 |
| 文字 | `#24211E` | 标题与正文 |
| 次级文字 | `#6F6962` | 说明、时间、空状态 |
| 边线 | `#DED9D0` | 卡片、表格、分隔 |
| 品牌动作 | `#D97745` | 主按钮、焦点、选中态 |
| 成功 | `#2F7D62` | 成功与在线状态 |
| 危险 | `#B84C43` | 删除与错误 |

- 字体：标题与正文统一 `Noto Sans SC`；编号、指标、英文眉题使用 `JetBrains Mono`。
- 字号：页面标题 32px，区块标题 20px，正文 14px，辅助信息 12px。
- 圆角：控件 4px、按钮 6px、容器 8px；不用胶囊形文字按钮。
- 阴影：默认无阴影；只允许悬浮层与重点纸张使用 `0 1px 2px rgba(36, 33, 30, .06)`。
- 间距：以 4px 为基数；常用 8 / 12 / 16 / 24 / 32px。

## 组件规则

- 按钮：一个页面只保留一个主动作；次要动作使用白底细边框；危险动作保持红色语义。
- 表单：标签在输入框上方，控件高度 40px，焦点统一为橙色外环。
- 卡片：只承载独立内容，不嵌套卡片；用边线和留白分层。
- 表格：表头浅纸色、12px 辅助字、行高不低于 48px，操作区不换行。
- 导航：用户端横向导航、管理端侧栏使用相同选中态；移动端必须可收起。
- 动效：只保留 120-180ms 的颜色/位移反馈，并尊重 `prefers-reduced-motion`。
