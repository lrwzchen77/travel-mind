# Sprint 2 Plan

## Goal

Build traditional business CRUD and a travel resource library backed by MySQL.

## Scope

- MySQL schema and seed data for users, preferences, cities, attractions, hotels, restaurants, tags, favorites, notes, trips, and AI records.
- Generic CRUD service and REST controller.
- Vue pages for resource management.
- Trip history persistence.

## Done Criteria

- CRUD list/detail/create/update/delete flows work.
- Resource filters support keyword, city, category, tag, and rating where applicable.
- Frontend pages can call backend APIs.
