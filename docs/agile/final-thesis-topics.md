# Travel Mind 团队论文题目定稿

## 统一技术栈与项目名称

`基于Spring Boot、Vue 3、FastAPI、MySQL、Redis和Qdrant的Travel Mind智能旅行规划系统`

## Wang-ke-li（组长）

《Travel Mind智能旅行规划系统（服务门户、旅行地图和路线规划、智能行程编排、TravelRisk-YOLO训练、旅行记忆与社区）》

模块边界：

1. 双端旅行服务门户：用户端与运营端登录、权限隔离和门户访问。
2. 3D旅行情报地图与路线规划：城市地点浏览、路线选择和地图旅行信息呈现。
3. 智能行程生成与动态编排：提交旅行需求、异步规划、进度推进和结构化行程生成。
4. TravelRisk-YOLO数据构建与迁移学习训练集成：与Zhu Qicheng共同完成旅行风险数据集、迁移学习训练、效果验证和系统应用集成。
5. 旅行记忆与社区内容流转：从已完成行程创建私密记忆、建立语义检索索引并基于证据问答；将确认内容发布至旅行社区并完成浏览、灵感包、点赞和评论。

## Chen Wenzhe

《Travel Mind智能旅行规划系统（目的地发现、行程历史、个人资料与偏好、收藏与旅行笔记）》

模块边界：

1. 目的地信息发现：城市、景点、酒店和餐饮信息的检索、浏览与详情查看。
2. 行程历史详情与复制管理：已生成行程的历史查看、详情展示、复制复用和删除。
3. 个人资料与旅行偏好管理：用户资料、预算、出行风格、交通、住宿和饮食偏好的维护。
4. 收藏与旅行笔记管理：旅行资源收藏及个人旅行笔记的创建、查看、修改和删除。

## Zhu Qicheng

《Travel Mind智能旅行规划系统（TravelRisk-YOLO风险识别、行程舒适度、旅行文本分析、AI服务降级）》

模块边界：

1. TravelRisk-YOLO推理服务与旅行风险提示：部署共同训练的模型，识别旅行场景、输出标签和置信度，并给出风险提醒。
2. 行程舒适度评估：依据单日景点密度、转场、天气、预算和偏好生成舒适度评分、风险等级与建议。
3. 旅行文本分析：从游记、评价和旅行内容中提取情感、关键词、亮点、注意事项和适宜人群。
4. 旅行AI服务状态与模型降级：提供AI健康检查；模型或推理资源不可用时，以规则结果维持稳定输出。

## Zhang Shuai

《Travel Mind智能旅行规划系统（目的地资源、地图POI与标签、用户账户与偏好、行程与AI记录）》

模块边界：

1. 目的地资源运营：城市、景点、酒店和餐饮资源的新增、查询、修改、发布状态维护和删除。
2. 地图POI与旅行标签维护：地图地点目录、地点属性和旅行标签的维护。
3. 用户账户与偏好运营：用户账户及其旅行偏好信息的查询和维护。
4. 行程计划与AI分析记录运营：平台行程计划及AI分析记录的查询、维护和运营侧管理。
